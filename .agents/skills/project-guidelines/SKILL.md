# Project Guidelines

Read `AGENTS.md` before acting. Read only the relevant `docs/` pages needed for the current task.

Decision rule:
- product behavior → `docs/product/`
- architecture → `docs/architecture/` and `docs/decisions/`
- domain calculation → `docs/domain/`
- quality/testing → `docs/quality/`
- agent workflow → `docs/ai/`

Keep changes small and testable.
