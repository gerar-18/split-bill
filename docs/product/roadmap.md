# Product Roadmap

| Milestone | Goal | Exit criterion |
|---|---|---|
| M0 | Engineering foundation | Repository, agent workflow, tests, documentation, CI-ready project |
| M1 | Split engine | Deterministic business logic with comprehensive tests |
| M2 | iOS UI | Complete manual split flow |
| M3 | Persistence | Receipts survive app restarts |
| M4 | Camera | Capture and preview receipt image |
| M5 | OCR | Image to text with evaluation fixtures |
| M6 | Intelligent parsing | OCR text to validated structured receipt |
| M7 | Backend | Cloud synchronization |
| M8 | Collaboration | Shared receipt workflow |
| M9 | Production | TestFlight, observability, production readiness |
